# 视频剪辑 Demo

双击 `index.html`，在桌面 Chrome 或 Edge 打开。预览读取 `assets/sample-browser.mp4`。联调时拖动时间轴滑块到第 8 秒附近，确认画面跳转，再点「分割」，时间轴应出现两段。

| 文件 | 负责方 | 职责 |
| --- | --- | --- |
| `index.html` | Mac | 视频预览、时间轴和操作按钮 |
| `styles.css` | Mac | 竖屏布局、白色播放头、高亮和触控尺寸 |
| `ui.js` | Mac | 根据状态渲染，转发滑动和点击 |
| `editor.js` | Windows | 管理项目状态、素材定位和分割 |

## 功能范围与分工

这是一个手机竖屏视频剪辑模块。用户可以导入素材，在时间轴上定位并预览画面，再编辑片段。

| 功能 | 用户操作 | 分工 | 当前进度 |
| --- | --- | --- | --- |
| 导入和预览 | 打开本地视频，播放、暂停或跳转到指定位置 | Windows 负责播放逻辑，Mac 负责界面 | 已接通内置视频和本地视频预览 |
| 时间轴 | 滑动定位画面，查看白色播放线，点选片段并高亮 | Mac 负责显示和手势，Windows 负责时间换算 | 滑块定位和高亮已接通，手机触屏待实机验证 |
| 片段编辑 | 在白线处拆分片段、删除选中片段或插入新素材 | Windows 负责编辑规则，Mac 负责操作按钮 | 分割、删除和插入已接通 |
| 片段排序 | 长按并拖动片段，调整播放顺序 | Mac 负责拖动，Windows 负责更新顺序 | 已在 Chrome 验证鼠标长按拖动 |
| 音频处理 | 编辑后让声音跟随对应的画面播放 | Windows 负责 | 原声由预览播放器随素材切换，实际出声待试听 |
| 导出视频 | 生成并下载视频，查看最终效果 | 单段裁剪已有原型 | 多段合成导出待实现和验证 |

## 接口约定

`createEditor(video)` 创建编辑器。`subscribe(listener)` 立即发送一次状态，并在状态变化后再次通知，返回取消订阅函数。界面读取状态中的 `clips`、`currentTime`、`duration`、`selectedClipId`、`playing`、`canSplit` 和 `error`。

| 调用 | 行为 | 进度 |
| --- | --- | --- |
| `seek(seconds)` | 按项目时间定位到素材画面，更新白线并选中所在片段 | 已接通 |
| `selectClip(clipId)` | 选中片段并更新高亮 | 已接通 |
| `splitAtPlayhead()` | 在选中片段内部按白线位置分割，更新片段列表 | 已接通 |
| `deleteClip(clipId)` | 删除片段并更新列表 | 已接通 |
| `moveClip(clipId, toIndex)` | 把片段移动到指定的零基索引，更新列表 | 已接通 |

`insertVideo(file)` 读取本地视频，插入播放线所在片段之后。时间轴为空时插入第一段。`togglePlayback()` 开始或暂停项目预览。

时间统一用秒。片段用稳定的 ID 识别。`start` 和 `end` 是素材时间，项目位置由前面片段的时长累加。例如，某段从原视频第 10 秒开始，放在项目第 5 秒，项目第 6 秒就对应原视频第 11 秒。分割时左段保留原 ID，右段获得新 ID。

独立音轨和多段合成导出待开发。Windows 侧负责桌面演示和华为触屏验证，Mac 侧负责 iPhone Safari 的滑动和长按验证。
